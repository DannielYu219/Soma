# Soma 0.1.2：持久化与提示缓存

## 新对话与多服务商

对话页左上角新增常驻“新对话”胶囊按钮，保留历史入口与 ⌘N。
模型服务支持添加、命名、编辑、切换和删除多个配置。每个配置保留协议、地址、密钥、主模型和可选检索模型；旧版单配置自动迁移。

## 持久化

App 通过 `/api/state` 将配置、外观、对话、文稿、草稿和活动会话写入 macOS Application Support 应用数据目录。网页 localStorage 仅作本地镜像，启动先从磁盘恢复。更新 App 不删除数据。

磁盘状态使用原子写入，目录 0700、文件 0600。API 仍由 App 的本机会话 cookie 保护。当前密钥保存在本机受权限保护的状态文件中，**尚未迁移到 macOS Keychain，也不是加密存储**。不要把状态文件随调试报告上传。

## 缓存策略

- 主对话 system 文本固定且精简，不放入日期、随机标识、当前作品 JSON 或服务配置。
- 作品内容追加在本轮用户消息尾部，历史消息和固定工具定义的前缀不随作品编辑变化。
- 工具内部循环保留原始 tool call / result 序列，不在未完成的工具调用中间插入额外用户消息。
- Anthropic 请求在 system、稳定工具定义、最近两个用户边界使用 ephemeral 提示缓存，总计不超过四个显式边界。内部检索和摘要请求也应用同样的固定前缀。
- 官方 OpenAI endpoint 设置确定性的 prompt_cache_key（模型和用途隔离、无明文密钥）；第三方兼容端点不强加 OpenAI 专用字段，避免协议错误。
- 不填充无意义 token、不用过期搜索答案冒充缓存、不跨会话共享用户内容。

**边界**：缓存能否命中仍取决于上游模型的最小 token 门槛、缓存保留时间、路由及服务商实现。没有真实生产 usage 数据就不能承诺命中率百分比。当前验证的是请求结构稳定和缓存参数正确，不声称实测命中率。

## 验证

单元与本地假上游集成测试覆盖：多配置迁移、磁盘重启恢复、并发原子保存、缓存 key 稳定性、四边界上限、Creator 修改不改变 system/tools/历史前缀、三协议调用和取消。

独立无头浏览器验证：多个服务添加切换，清空浏览器镜像后从磁盘恢复、草稿、常驻新对话按钮、OOBE、Creator、快速模型选择。
