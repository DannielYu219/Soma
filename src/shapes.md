# 形状规则

## 胶囊

端头必须是**半圆**：半径等于高度的一半，用普通 `border-radius: 999px`。

不要用平滑曲线路径（`Surface` / `continuous.ts`）去近似胶囊。那套曲线的端部比半圆更"方"，满半径时看起来是圆角矩形而不是胶囊——这是踩过的坑。

## 圆角矩形

用 `Surface` 的连续曲率路径。注意 `getContinuousPath` 的 `radius` 参数不是视觉半径：实际端部尺寸是 `radius * 1.45`。想要视觉上 26px，传 26 / 1.45 ≈ 18。

## 通用

- 内层圆角 = 外层圆角 − 内边距，保持同心。
- 形状放在独立的绘制层，内容、焦点环、弹层不要被裁切。
- `corner-shape: round` 只能当渐进增强，不能当几何基准。
